# Tools
*用 Python 写的工具合集，非 AI 生成*

*作者：T-PageCode*

## 📃 项目介绍
这是一个工具合集，all.py 中集合了所有功能（写入、读取、追加、编码、解码、删除）6 款工具，并增加了注释，小白也能看懂。
**本项目非 AI 生成，但用 AI 来 Code Review 和 查Bug。**

## ⭐ 功能特性
1. **完美截获 *FileNotFoundError* 、 *SyntaxError* 、*ValueError*、*PermissionError* 以及 *Exception* 捕获其他错误。**
2. **整整 6 款工具，写入、读取、追加、编码、解码、删除等常用操作统一在这个小工具里面进行。**
3. **纯原生命令行，速度远比图形界面快。**

## 💻 如何运行
安装 **Python** 后，**切换到仓库文件夹**执行此命令。
```bash
python all.py
```
或运行单个工具：
```bash
# 写入
python write.py
# 读取
python read.py
# 追加
python add.py
# 编码
python encode.py
# 解码
python decode.py
# 删除
python delete.py
```
